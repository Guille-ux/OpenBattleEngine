# OpenBattleEngine

it's a battle engine is a port from one i made in godot, idk



## USE OF AI:
there are some portions of code that may be ai generated, those are 
A: code i writed in gdscript so i told ai to rewrite it in python, (for example, the IGA)
B: some random ai's that chatgpt o gemini made to test iga
C: the tournament code, because i was to lazy yk

## How To Run
if you wanna make 2 ai's compete, edit game.py to select the 2 ai's
then run `python3 game.py`, if you wanna train the iga, you can just
run `python3 game.py train`, if you wanna add a new ai, just read the doc's file
